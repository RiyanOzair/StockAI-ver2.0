Steps to Run Project:
1. Ensure Python 3.9+ is installed on your system.
2. Navigate to the 'Code' folder and extract its contents.
3. Follow the installation steps in 'Software/setup_software.txt' to set up the virtual environment and install dependencies.
4. Run the simulation server using 'python backend/run.py'.
5. Open your browser and go to http://127.0.0.1:8000.

Notes:
- Ensure all dependencies are installed via 'pip install -r requirements.txt' inside a virtual environment.
- Follow the 'Instruction Manual' for detailed configuration of AI providers (Groq/Gemini/OpenAI).
- The project is designed to be local-first; the simulation logic is processed entirely on the host machine.
