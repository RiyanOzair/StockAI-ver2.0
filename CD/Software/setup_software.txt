STOCKAI v2.0 - SETUP INSTRUCTIONS
==============================

StockAI is a web-based market simulation platform built with FastAPI (Python) and Vanilla JavaScript.

DEPENDENCIES:
-------------
- Python 3.9 or higher
- Pip (Python Package Manager)
- (Optional) AI Provider API Keys (Groq, OpenAI, or Google Gemini)

INSTALLATION STEPS:
-------------------
1. Extract the 'Code' folder to your local machine.
2. Open a terminal/command prompt in the project root.
3. Create a virtual environment:
   python -m venv .venv
4. Activate the virtual environment:
   Windows: .\.venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate
5. Install required packages:
   pip install -r requirements.txt
6. (Optional) Configure API keys:
   - Copy .env.example to .env
   - Add your API keys for LLM features.

ENVIRONMENT SETUP:
------------------
- Ensure you have a stable internet connection for LLM-backed features.
- The system uses an internal SQLite database (stockai_research.db) for persistence, which is automatically initialized.

HOW TO RUN:
-----------
Run the following command from the root directory:
python backend/run.py

Access the application at:
http://127.0.0.1:8000
